# Simulación Estación Espacial 🚀

> ⚠️ **Proyecto archivado.** La versión final y evolucionada de este prototipo vive en **[SpacialStation](https://github.com/JoshuaLopez2000/SpacialStation)**: simulación VR de desorientación espacial con video demo, documentación completa y créditos de assets.

---

Prototipo de simulación en **realidad virtual** (Unity `6000.0.41f1`) de una estación espacial, creado como proyecto de simulación (C# + URP). El desarrollo activo continuó en `SpacialStation`, donde se pulió el entorno 3D, las interacciones (botones 3D, visor del astronauta, hologramas) y los efectos de shaders.
